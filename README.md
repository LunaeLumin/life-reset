# Life Reset PWA 0.8.0

Персональное приложение на русском языке: привычки, XP, характеристики, цели и финансы. HTML, CSS и JavaScript, без сервера и регистрации.

## Новое в 0.8.0

- Дни недели для каждой привычки. На главной — только задания по расписанию; вся история сохраняется. В списке можно нажать на название или «Изменить». Смена названия, категории и расписания сохраняет ID, отметки и XP. При конфликте вкладок редактирование отклоняется.
- Категории: спорт, интеллект, питание. Прежнее здоровье переносится в спорт; развитие, дисциплина и финансы — в интеллект. Исходная категория записана в `previousCategory`, прежние финансовые записи сохранены. У новых пользователей вместо финансовой привычки — привычка питания.
- Цели: редактирование нажатием, необязательная дата окончания, оставшиеся дни и шаги выполнения. «+ Шаг» двигает шкалу, «− Шаг» отменяет ошибку. Истечение срока не завершает цель. Шаги целей не начисляют дополнительный XP.
- Вкладка «Прогресс» вместо финансов: сохранённые выполнения, активные дни, небольшие этапы по 5 действий и прогресс каждой привычки. Календарь недели/месяца/года остаётся в «Привычки → История».
- Мужской и женский SVG-персонажи с четырьмя этапами развития. Пол сохраняется в меню персонажа; характеристики перенесены туда с главного экрана.
- Финансовые записи доступны через «Ещё → Архив финансов» и включены в экспорт. Уведомлений нет.

## Формат и обновление

Ключ остаётся `life-reset-v2`. Текущий формат — **4**, импорт поддерживает 2, 3 и 4. Старые цели преобразуются в объекты с постоянными ID; повторяющиеся названия допустимы. Привычки без расписания считаются ежедневными. XP, история, финансы и дополнительные поля сохраняются. Сроки используют местную дату телефона, календарные вычисления не зависят от перехода на летнее время.

Чтение само по себе не записывает миграцию. Перед первой записью версии 2/3 точная исходная запись сохраняется под `life-reset-v2-before-0.8.0`. Скачать её можно через «Ещё → Копия до обновления 0.8». Если копия не помещается, запись отменяется. Существующие копии до импорта и обновления 0.4.1 также сохраняются. При явном сбросе удаляются все три копии. Старые окна не принимают формат 4: после выпуска следует переоткрыть приложение.

Тестовая версия `preview/0.8.0/` использует отдельный ключ `lr-preview-0.8.0`, отдельную очередь записи и офлайн-кэш. Изменения тестовой версии не переносятся автоматически в основное приложение. Сборка: `node scripts/build-preview.cjs <папка>`. Файл `preview.json` содержит исходный коммит и контрольные суммы.

## История привычек

В разделе «Привычки» появилась вкладка «История». Выберите привычку и период: неделя с понедельника, календарный месяц или год. Счётчик показывает количество дней с выполнением выбранной привычки за этот период. Стрелки открывают прошлые периоды, «К текущему» возвращает к сегодняшнему.

Цветной квадрат — выполнение, чёрный — день без отметки, пунктирный — будущий день. Нажатие показывает дату и статус, не меняя отметку. В годовом виде сетка прокручивается горизонтально внутри карточки. Цвет выполнений соответствует текущему рангу персонажа.

История читает существующие `checks`, поэтому прежние отметки и импортированные копии видны сразу. Новый формат данных не нужен; просмотр не записывает данные и не начисляет XP. Дата создания привычки в старых данных неизвестна: чёрный означает «Не отмечено», включая дни до её добавления. Как и раньше, удаление привычки с подтверждением удаляет её историю и соответствующий XP.

Календарь использует местную дату телефона. При наступлении полуночи и возвращении в приложение он обновляется, сохраняя выбранные прошлые периоды. Все файлы календаря включены в офлайн-кэш.

## Ранее реализовано

- Новый персонаж — стилизованный человек, нарисованный SVG-кодом. Четыре ранга: «Новичок» (1–2), «Любитель» (3–5), «Атлет» (6–9), «Титан» (10+). Меняются осанка, ширина торса и плеч, толщина рук, мышцы, причёска и спортивная одежда. У Титана появляется аура.
- SVG сохраняет DOM-узлы при смене ранга, а CSS transitions плавно меняют трансформации, цвет и прозрачность деталей. Уменьшение движения в iOS отключает анимации.
- Нажатие на аватар в приложении открывает крупного персонажа с фактическими XP и уровнем. Отдельная страница `avatar-demo.html` содержит кнопки «+25 XP», «+100 XP», «Сброс» и быстрый выбор ранга. Демонстрационный опыт хранится только в памяти страницы и не меняет записи Life Reset.
- Для зависших сетевых запросов Service Worker использует кэш через 2,5 секунды. Это ограничивает ожидание при слабом соединении во время офлайн-запуска.
- После отмены удаления привычки кнопка возвращается к исходному виду на сенсорном экране. Эффект наведения действует только при работе мышью.
- Любую финансовую операцию можно удалить с подтверждением. Доходы, расходы, погашения долга и итоговый баланс пересчитываются. Старые записи с одинаковыми ID удаляются по отдельности; при конфликте вкладок или ошибке записи операция сохраняется.
- На главном экране аватар и цвет акцента соответствуют текущему рангу. Каждый новый уровень отмечается короткой анимацией и сообщением; настройка уменьшения движения в iOS учитывается.
- Внешний вид вычисляется из существующего XP. При снижении уровня облик и цвет возвращаются к соответствующему этапу. Переноса данных или нового счётчика опыта нет.
- Каждая запись проверяется и сохраняется до сообщения об успехе. При ошибке финансовые поля и диалог привычки сохраняют введённые значения. Неудачно добавленная цель остаётся в следующем диалоге добавления.
- Импорт проверяет все привычки, категории, даты, отметки, цели и операции. Строковые суммы, повторяющиеся ID привычек и повреждённые записи отклоняются целиком.
- Перед импортом сохраняется точная предыдущая запись. Последнюю копию можно скачать в разделе «Ещё» → «Копия до импорта».
- Повреждённые или неизвестные версии данных не заменяются начальными данными. Предупреждение предлагает скачать исходную запись и импортировать исправную копию.
- Изменения между окнами синхронизируются. Записи выполняются по очереди с повторным чтением актуальных данных. Импорт и удаление отклоняются, если после открытия подтверждения данные успели измениться.
- Экспорт доступен даже при переполненном хранилище. Сообщение «Файл резервной копии подготовлен» означает начало скачивания; сохранение файла на устройство подтверждает пользователь.
- Service Worker обновлён и сохраняет новый файл `data.js` для офлайн-запуска.

## Совместимость данных

Основной ключ остаётся **`life-reset-v2`**, формат сохраняемых данных — **4**. Версия интерфейса 0.8.0 и версия формата — разные вещи. Обновление преобразует структуру целей и расписаний, сохраняя заработанный XP и исходную копию данных.

Поддерживаются копии форматов 2, 3 и 4. В формате 2 XP мог начисляться навсегда, даже после снятия галочки. При переходе этот ранее заработанный опыт сохраняется в `legacyXp`, а исторический прогресс категорий — в `legacyCounts`. Новые отметки по-прежнему дают 20 XP, снятие новой отметки отменяет эти 20 XP. Личный фокус сохраняется до нажатия «Другой совет». Другие поля исходной копии также сохраняются.

Перед первой записью преобразованных данных формата 2 исходный текст сохраняется под ключом `life-reset-v2-before-0.4.1`. Кнопка «Копия до обновления» позволяет скачать его. Перед импортом предыдущая запись сохраняется под ключом `life-reset-v2-before-import`; при следующем импорте эта копия заменяется. Если для копии нет места, замена основных данных отменяется. При ошибке сохранения исходная основная запись остаётся на месте.

«Удалить все данные» требует подтверждения и удаляет также обе локальные копии. Они находятся в том же браузере и не заменяют экспорт в отдельный файл: очистка данных Safari может удалить всё локальное хранилище.

Очередь IndexedDB хранит идентификатор последней записи, а Web Locks дополнительно координирует окна там, где этот API доступен. Это предотвращает перезапись даже при задержке обновления локального хранилища в соседней вкладке. Если свежие данные ещё не пришли, приложение кратко повторяет проверку, затем предлагает повторить действие. Если механизм безопасной записи недоступен, приложение сообщает об ошибке и не записывает данные. Старые открытые окна версии 0.4 не знают об этой защите: после обновления следует закрыть и снова открыть все окна Life Reset.

## Запуск и iPhone

Откройте https://lunaelumin.github.io/life-reset/ в Safari → Поделиться → На экран «Домой». После первого успешного открытия приложение работает офлайн. Хранилища Safari и установленного приложения могут различаться; для переноса используйте экспорт и импорт.

Для локальной разработки достаточно статического HTTP-сервера, например `python3 -m http.server 8000`. В текущей реализации Service Worker регистрируется только по HTTPS.

## Отдельная тестовая версия

`preview/0.8.0/` на GitHub Pages содержит снимок версии из pull request. Он собирается командой `node scripts/build-preview.cjs <папка-результат>`; версия берётся из `package.json`, а файл `preview.json` фиксирует исходный коммит и контрольные суммы файлов. SVG, аватар, календарь, CSS и демостраница включаются в снимок и офлайн-кэш.

У теста отдельные ключи данных, копий и очереди записи (`lr-preview-0.8.0`), отдельный кэш и область Service Worker. Импорт, изменения и сброс в тесте не изменяют основную запись `life-reset-v2` или прежние тестовые версии. В Safari можно установить его отдельно под именем «LR Тест». Изменения из теста автоматически не переносятся в основное приложение. При публикации снимка в `main` обновляется только папка `preview/0.8.0/`; основной интерфейс остаётся на прежней версии.

## Компонент аватара

Подключите `avatar.css`, затем `progression.js` и `avatar-component.js`. SVG полностью создаётся кодом, внешних изображений и библиотек нет.

```js
const avatar = LifeResetAvatar.mount(document.getElementById('avatar'), {
  xp: 0,
  demo: true // false для отображения реального прогресса без XP-кнопок
});
avatar.setXP(2500, { celebrate: true }); // LVL 6, «Атлет»
avatar.getXP();
avatar.destroy();
```

Каждый уровень требует 500 XP, как в основном приложении. Компонент не обращается к `localStorage` или IndexedDB: сохранением фактического опыта управляет приложение.

## Проверки

Node.js 22+, npm, Git и OpenSSL:

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

Для установленного системного Chromium:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser
```

Модульные тесты проверяют преобразования форматов, повреждённые копии, переполнение хранилища, конфликты и границы рангов. Браузерные тесты проверяют две вкладки, удаление операций, отмену удаления на сенсорном экране, повышение/снижение уровня, уменьшение движения, кнопки демо, изоляцию тестового XP и сохранение SVG-узлов при анимации. Календарь проверяется на високосных годах, границах недели, местной полуночи, разных часовых поясах, пустых привычках, импорте и офлайн-просмотре. Проверка обновления с 0.6.0 использует исходный коммит `883c9e4834e22d5fb70995526835de5c68f05c2d`. Офлайн-запуск также проверяется при зависающих сетевых запросах.

Перед публикацией дополнительно проверить на настоящем iPhone: установку на главный экран, скачивание JSON в «Файлы», восстановление копии, возврат после блокировки экрана и запуск в авиарежиме. Автоматические тесты Chromium не проверяют особенности iOS Safari.
