# Life Reset PWA 0.2

## Включено
- Минималистичный адаптивный интерфейс на русском.
- Dashboard: уровень, XP, характеристики, фокус дня.
- Ежедневные задания: 20 XP за каждое, начисление не дублируется в течение дня.
- Привычки: добавление пользовательских заданий.
- Цели: добавление и удаление.
- Финансы: доходы, расходы, погашение долга, баланс и история.
- Аналитика: общий XP, текущий уровень, сводка.
- Экспорт и импорт резервной копии JSON.
- Сброс сегодняшних отметок и полное удаление данных с подтверждением.
- PWA manifest, иконка, service worker и офлайн-кэш.

## Установка на iPhone
1. Разместить содержимое этой папки на HTTPS-хостинге.
2. Открыть адрес в Safari.
3. Нажать «Поделиться» → «На экран Домой».
4. Запустить приложение с иконки.

## Важно
Данные пока хранятся локально в браузере на конкретном устройстве. Экспортируйте резервную копию регулярно. Синхронизация, аккаунты, push-уведомления и интеграция с Apple Health не реализованы. Для push-уведомлений и облачной синхронизации потребуется сервер и настройка инфраструктуры.
