# Life Reset PWA 0.4.1

Персональное приложение на русском языке: привычки, XP, характеристики, цели и финансы. HTML, CSS и JavaScript, без сервера и регистрации.

## Что исправлено

- Каждая запись проверяется и сохраняется до сообщения об успехе. При ошибке финансовые поля и диалог привычки сохраняют введённые значения. Неудачно добавленная цель остаётся в следующем диалоге добавления.
- Импорт проверяет все привычки, категории, даты, отметки, цели и операции. Строковые суммы, повторяющиеся ID привычек и повреждённые записи отклоняются целиком.
- Перед импортом сохраняется точная предыдущая запись. Последнюю копию можно скачать в разделе «Ещё» → «Копия до импорта».
- Повреждённые или неизвестные версии данных не заменяются начальными данными. Предупреждение предлагает скачать исходную запись и импортировать исправную копию.
- Изменения между окнами синхронизируются. Записи выполняются по очереди с повторным чтением актуальных данных. Импорт и удаление отклоняются, если после открытия подтверждения данные успели измениться.
- Экспорт доступен даже при переполненном хранилище. Сообщение «Файл резервной копии подготовлен» означает начало скачивания; сохранение файла на устройство подтверждает пользователь.
- Service Worker обновлён и сохраняет новый файл `data.js` для офлайн-запуска.

## Совместимость данных

Основной ключ остаётся **`life-reset-v2`**, формат сохраняемых данных — **3**. Версия интерфейса 0.4.1 и версия формата — разные вещи.

Поддерживаются копии форматов 2 и 3. В формате 2 XP мог начисляться навсегда, даже после снятия галочки. При переходе этот ранее заработанный опыт сохраняется в `legacyXp`, а исторический прогресс категорий — в `legacyCounts`. Новые отметки по-прежнему дают 20 XP, снятие новой отметки отменяет эти 20 XP. Личный фокус сохраняется до нажатия «Другой совет». Другие поля исходной копии также сохраняются.

Перед первой записью преобразованных данных формата 2 исходный текст сохраняется под ключом `life-reset-v2-before-0.4.1`. Кнопка «Копия до обновления» позволяет скачать его. Перед импортом предыдущая запись сохраняется под ключом `life-reset-v2-before-import`; при следующем импорте эта копия заменяется. Если для копии нет места, замена основных данных отменяется. При ошибке сохранения исходная основная запись остаётся на месте.

«Удалить все данные» требует подтверждения и удаляет также обе локальные копии. Они находятся в том же браузере и не заменяют экспорт в отдельный файл: очистка данных Safari может удалить всё локальное хранилище.

Очередь IndexedDB хранит идентификатор последней записи, а Web Locks дополнительно координирует окна там, где этот API доступен. Это предотвращает перезапись даже при задержке обновления локального хранилища в соседней вкладке. Если свежие данные ещё не пришли, приложение кратко повторяет проверку, затем предлагает повторить действие. Если механизм безопасной записи недоступен, приложение сообщает об ошибке и не записывает данные. Старые открытые окна версии 0.4 не знают об этой защите: после обновления следует закрыть и снова открыть все окна Life Reset.

## Запуск и iPhone

Откройте https://lunaelumin.github.io/life-reset/ в Safari → Поделиться → На экран «Домой». После первого успешного открытия приложение работает офлайн. Хранилища Safari и установленного приложения могут различаться; для переноса используйте экспорт и импорт.

Для локальной разработки достаточно статического HTTP-сервера, например `python3 -m http.server 8000`. В текущей реализации Service Worker регистрируется только по HTTPS.

## Проверки

Node.js 22+, npm, Git и OpenSSL:

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

Для установленного системного Chromium:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser
```

Модульные тесты проверяют преобразования форматов, повреждённые копии, переполнение хранилища и конфликты. Браузерные тесты поднимают временный HTTPS-сервер и проверяют реальные действия, две вкладки, экспорт/импорт и обновление Service Worker с 0.4 на 0.4.1 с последующим офлайн-запуском. Для последнего сценария нужен исходный коммит `d17a393806524b1791664bf043ce516c02c93e2f` в истории Git.

Перед публикацией дополнительно проверить на настоящем iPhone: установку на главный экран, скачивание JSON в «Файлы», восстановление копии, возврат после блокировки экрана и запуск в авиарежиме. Автоматические тесты Chromium не проверяют особенности iOS Safari.
