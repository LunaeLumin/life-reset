# Life Reset PWA 0.3

## Исправления
- XP и характеристики пересчитываются по галочкам. +20 XP при выполнении и −20 XP при снятии.
- Кнопка «Другой совет» показывает один из 20 советов.
- Новая привычка добавляется через диалог с выбором категории.
- Офлайн-кэш обновлён до версии 0.3.

## Данные
Существующие записи v0.2 сохраняются на том же устройстве. XP пересчитывается по выполненным заданиям; ранее выданный XP за снятые галочки исключается. Рекомендуется экспортировать резервную копию в разделе «Ещё» перед обновлением.

## Запуск
Откройте https://lunaelumin.github.io/life-reset/ на iPhone в Safari → Поделиться → На экран «Домой».
